# v0.5.0

Stable release of the revived Prometheus Alertmanager plugin, following
pre-release validation in v0.5.0-rc.1 and v0.5.0-rc.2. The previous stable
release was v0.4.0.

## Compatibility

- Requires Mattermost **11.7+**; validated on **11.7.14** and **12.0.0**.
- Building requires Go **1.27+**, Node **24.11+**, and npm **10+**.
- The plugin ID remains `alertmanager`, and existing configurations retain
  their default notification format.

## Changes since v0.4.0

- Add optional HTTP Basic Authentication credentials to each Alertmanager
  configuration. Credentials are used for status, alert and silence requests,
  including silence expiration. Leave them blank when authentication is not
  required; the password is masked in plugin settings.
- Add severity colors to webhook notifications and `/alertmanager alerts`:
  blue for `info`, yellow for `warning`, red for `high`/`critical` and unknown
  severities, and green for resolved alerts.
- Render grouped webhooks as one post with an attachment per alert, preserving
  individual status and severity. Add optional title/message Go templates per
  destination, with a preview CLI and fallback to the detailed format for
  invalid templates.
- Improve silence action handling and HTTP retry behavior, and preserve TLS
  certificate validation errors instead of hiding them behind a retry timeout.
- Document Alertmanager HA and provide a three-peer Docker test environment.
  The integration workflow checks notification deduplication across connected
  peers.
- Update Mattermost SDK and Alertmanager dependencies, support Mattermost 11.7+
  and React 18/19, and modernize the build and signed release artifact workflow.

## Validation

The v0.5.0 release candidate was validated on Mattermost 11.7.14 and 12.0.0.
Docker smoke checks cover firing and resolved notifications and slash commands;
the HA smoke test checks connected-peer deduplication. CI for the Basic Auth
change passed build, Go tests and lint. Its HTTP client test verifies
authenticated status, alert listing, silence listing and silence expiration.
The credentials settings UI passes lint and the production build; a browser
save/reload check with credentials is not part of the automated integration
smoke test.

## Known limitations

- Alertmanager HA provides at-least-once delivery and can send duplicate
  notifications during network partitions.
- Template fallback text is provided, but mobile push presentation depends on
  Mattermost notification settings.
