# v0.5.0-rc.2

Second release candidate for the revived Prometheus Alertmanager plugin. This
pre-release adds configurable compact notifications and includes fixes and
validation since v0.5.0-rc.1. The previous stable release remains v0.4.0.

## Compatibility

- Requires Mattermost **11.7+**; validated on **11.7.14** and **12.0.0**.
- Building requires Go **1.27+**, Node **24.11+**, and npm **10+**.
- The plugin ID remains `alertmanager`, and existing destinations retain their
  default notification format unless custom templates are configured.

## Changes since RC1

- Add severity colors to webhook notifications and `/alertmanager alerts`:
  blue for `info`, yellow for `warning`, red for `high`/`critical` and unknown
  severities, and green for resolved alerts.
- Render grouped webhooks as one post with an attachment per alert, preserving
  individual status and severity. Highlight summaries and descriptions, simplify
  source links and timestamps, and move configuration/receiver details to a footer.
- Add optional title/message Go templates per destination in System Console.
  Templates render compact attachments with automatic colors and fallback text;
  invalid templates fall back to the detailed format to preserve delivery.
- Add a shared-renderer preview CLI, `make template-preview`, sample webhook and
  template files, a dedicated CLI README and updated screenshots.
- Return original TLS certificate validation errors immediately instead of
  hiding them behind a generic retry deadline. Document connection diagnostics.
- Document Alertmanager HA configuration and provide a three-peer Docker overlay
  with `dev-ha-up`, `dev-ha-smoke` and `dev-ha-down`. Connected peers produced one
  firing and one resolved notification; three isolated instances produced three
  of each. The integration workflow now includes the HA smoke test.
- Upgrade the frontend build tools to Babel 8 and ESLint 10, update the development
  React dependency, and preserve the host-provided React runtime with classic JSX.
- Update pinned GitHub Actions and migrate Cosign 3 release signing to a
  `.sigstore.json` verification bundle. Signature verification instructions cover
  both the new bundle and RC1's legacy `.sig`/`.pem` files.

## Validation

Server/renderer/CLI race tests, Go and frontend lint, the production webapp and
all five server build targets pass. Standalone Docker smoke checks pass on
Mattermost 11.7.14 and 12.0.0. Browser checks verify template editing, token
regeneration and save/reload persistence on both versions. Real webhook
attachments match the preview CLI's title, body, fallback and colors, and syntax
or execution failures still deliver default notifications. The local three-peer
HA test verifies one firing and one resolved notification after observing all
peer notification delays.

## Remaining scope

Dedicated Basic Auth settings remain pending in issue #7 / PR #604. The TLS
change improves diagnostics; it does not fix arbitrary network or handshake
failures. Alertmanager HA still provides at-least-once delivery and can send
duplicate notifications during network partitions. Template fallback text is
provided, but mobile push presentation depends on Mattermost notification settings.
